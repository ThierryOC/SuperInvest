# SuperInvest

**Painel de análise de investimentos (mercado brasileiro) — ações, FIIs, criptomoedas e renda fixa.**
*Investment screening dashboard for the Brazilian market — stocks, REITs (FIIs), crypto and fixed income.*

</div>

---

> ⚠️ **Isto não é recomendação de investimento / This is not investment advice.**
> SuperInvest é um projeto experimental e educacional. Os rankings e classificações mostrados são o resultado mecânico de modelos estatísticos, para fins de estudo — nunca uma indicação de compra ou venda. Toda decisão de investimento é sua, e só sua.
> *SuperInvest is an experimental, educational project. Rankings and classifications shown are the mechanical output of statistical models, for study purposes only — never a buy/sell indication. Every investment decision is yours alone.*

## Acesso

O programa abre com uma tela de login — **o instalador é público, mas o acesso não é**: cada conta é criada manualmente por mim. Pra solicitar um login, [**abra uma Issue neste repositório**](../../issues/new) pedindo acesso.
*The app opens behind a login screen — **the installer is public, but access isn't**: each account is created manually by me. To request a login, [**open an Issue on this repository**](../../issues/new) asking for access.*
